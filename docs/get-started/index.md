# Get started

AI App Server is one program, `aiapp`, that runs AI applications on your own machine or servers.

**Who it is for**

- **App developers** who want a working AI app (chat over documents, extraction, an agent) without building a web service, a vector database and a job queue first.
- **IT and platform teams** who want those apps to run safely: sign-in, audit, quotas, encrypted storage, monitoring.

**Everything is in one public repository:** [github.com/Sandaal/ai-app-server](https://github.com/Sandaal/ai-app-server): releases, example apps, the SDK source and deployment templates ([what's there](../reference/repository.md)).

**Where to go next**

1. [How it works](how-it-works.md): the five ideas behind the server, in two minutes.
2. [Quickstart](quickstart.md): install, connect a model, and chat with your documents in ten minutes.
3. Then pick a path:
    - [Build apps](../build/index.md) if you write the apps.
    - [Operate](../operate/index.md) if you run the server for others.
