# Security policy

Please report security vulnerabilities privately, using GitHub's **Report a vulnerability** button on the [Security tab](https://github.com/Sandaal/aiapp-server/security) of this repository. Don't open public issues for them.

Include the version (`aiapp version`), what you found, and how to reproduce it. We aim to reply within a few working days.

Security guidance for running the server: https://sandaal.github.io/aiapp-server/operate/security/
