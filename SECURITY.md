# Security Policy

## Reporting a vulnerability
**Do not open a public issue for security problems.**

Report vulnerabilities privately through GitHub: on this repository, go to the **Security** tab and choose **Report a vulnerability**. Include a description, steps to reproduce, affected versions, and the impact you expect.

You will get an acknowledgement within a few days. A fix and coordinated disclosure date will be agreed with you before details are made public.

## Supported versions
The project has no releases yet. Once releases begin, this section will list which versions receive security fixes.
